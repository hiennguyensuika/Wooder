
1.	What is the Product ? 
- Wooder is a responsive landing page website for a wood-based interior design brand. It is designed to showcase products, services, and company style in a visually attractive way.

2.	What are key features ?
- Fully responsive design (mobile, tablet, desktop)
- Smooth scrolling animations
- Product showcase with images and categories
- Contact form (UI only, not connected to backend)
- Organized layout using SCSS and modular HTML
- Font, image, and icon assets optimized for web

3.	How is the Workflow ?
-  Page are written in modular HTML, SCSS and JS files.
-  GruntJS tasks: Used to compile SCSS → CSS, and minify files.
-  Live reload (optional): Can be set up to auto-refresh on file changes during development.
-  Deploy: Code can be pushed to GitHub and deployed on platforms like Netlify.

4.	Steps to Run Repo:
    - Step 1: Clone the repo
      git clone https://github.com/hiennguyensuika/Wooder.git

    - Step 2: Navigate into the project folder
      cd wooder

    - Step 3: Install project dependencies
      npm install

    - Step 4: Run grunt to build the project
      grunt

    - Step 5: Use Live Server | Go live | Open "index.html" in your browser (Optional)

5.	The highlights of the Repo:
- Built with SCSS, making styling modular and maintainable
- Uses Grunt to automate tasks like compiling and minifying
- Optimized for responsive layout across devices
- Beautiful layout suitable for a design-focused business
- Clean folder structure (scss, js, img, fonts, etc.)
